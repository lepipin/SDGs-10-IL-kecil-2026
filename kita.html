Tujuan membuat website

Saya membuat website ini untuk projek sekolaj IL kecil yang berkolaborasi dengan 3 matapelajaran (PPKN, IPS, dan TIK)

Di website ini saya membahas banyak topik seperti SDGs (kebanyakan SDGs 10 yaitu berkurangan kesenjangn) dan juga jenis-jenis kerjasama!!

Semoga website yang saya buat dapat membantu anda mendapat info tentang topik-topik ini terima kasih ^u^

Refleksi

Hal-hal yang saya pelajari selama mengerjakan proyek ini.

Hal yang Saya Pelajari

Melalui proyek ini, saya memahami bahwa kerja sama antarnegara, baik secara bilateral, regional, maupun multilateral, memiliki peran penting dalam mengatasi permasalahan global. Saya juga mendapat pengalaman baru dalam membuat website menggunakan HTML dan CSS, mulai dari menyusun informasi, mengatur tata letak, hingga memadukan warna dan gambar agar website lebih menarik dan mudah dipahami.

Tantangan dan Kesan

Salah satu tantangan terbesar adalah mengatur desain website agar setiap bagian terlihat rapi dan tidak saling bertabrakan. Walaupun terkadang sulit, proses mencoba dan memperbaiki kode membuat saya semakin memahami HTML dan CSS. Saya juga menyadari bahwa mengurangi kesenjangan bukan hanya tanggung jawab pemerintah, tetapi membutuhkan kepedulian seluruh masyarakat. Saya berharap dapat menerapkan nilai menghargai perbedaan dan memberikan kesempatan yang sama kepada orang lain.

Every project is a chance to learn something new!
